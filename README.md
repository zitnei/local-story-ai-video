# ローカル ストーリーAI

自分のPCで動くAI（MiniMaxなど）を使い、**5秒ごとにプロンプトを取り込んで、つながった物語を自動で書き続ける**サイトです。

## 使い方

1. LM Studio / Ollama などで MiniMax のモデルを読み込み、ローカルサーバーを起動する
   - LM Studio：「Developer」タブ → Start Server（`http://127.0.0.1:1234/v1`）
   - Ollama：`ollama serve`（`http://127.0.0.1:11434/v1`）
2. `start.bat` をダブルクリック（または `node server.js`）→ http://localhost:3000 が開く
3. 左の「AI接続設定」でURLを選び、「取得」でモデル名を選ぶ
4. 「物語の設定」にタイトル・世界観・登場人物を書く（毎回AIに渡され、設定ブレを防ぎます）
5. 下の入力欄に最初の展開を入れて「追加」→「▶ 開始」
6. 実行中も好きなタイミングでプロンプトを追加できます。5秒ごとに1つずつ取り込まれます

AIが無くても「テストモード」にチェックを入れると画面の動作確認ができます。

## 話がつながるしくみ

| 仕組み | 内容 |
|---|---|
| 順番待ちキュー | 入力したプロンプトは順番に1つずつ処理。前の生成が終わるまで次は始まりません |
| 作品設定 | タイトル・世界観・登場人物を毎回AIに渡します |
| 直前の本文 | 最近の段落をそのまま渡し、最後の一文の直後から続けさせます |
| 自動あらすじ | 古い段落は定期的に要約して「あらすじ」に統合（人物の状態・伏線・持ち物を保持）。長編でも矛盾しにくくなります。あらすじは手で編集もできます |
| 推論の除去 | `<think>…</think>` の推論部分は本文に入れません |
| 重複除去 | AIが直前の文を繰り返して書き始めた場合は取り除きます |
| 自動で続き | プロンプトが無い時も、流れに沿って続きを書きます（オフ可） |

物語は自動でブラウザに保存されます。TXT / JSON で書き出し・読み込みもできます。

## 🎬 動画生成

段落ごとに「映像クリップ」「ナレーション」を作り、字幕つきの1本の MP4 にまとめます。
完成した動画は `output/videos/` に保存されます。

### 映像の作り方は2種類

| モード | 必要なもの | 内容 |
|---|---|---|
| ComfyUI でAI動画 | ComfyUI ＋ 動画モデル | 段落ごとにAIがシーン指示（英語）を書き、ComfyUIで数秒の動画を生成 |
| AIなし | なし | 暗い背景＋字幕＋ナレーション（すぐ使えます） |

ナレーションは Windows 標準の音声（Microsoft Haruka）、結合は ffmpeg を使います。

### 標準ワークフロー（読み込み不要）

`workflows/` に、次のモデル用のワークフローが入っています。最初に画面を開くと自動で設定されます。

| ファイル | 置き場所（ComfyUI フォルダ内） |
|---|---|
| `wan2.1_vace_1.3B_fp16.safetensors` | `models/diffusion_models` |
| `umt5_xxl_fp8_e4m3fn_scaled.safetensors` | `models/text_encoders` |
| `wan_2.1_vae.safetensors` | `models/vae` |

| ワークフロー | 用途 |
|---|---|
| 標準：文章→動画 | 物語の段落・タイムライン（参照動画なし） |
| 標準：動画→動画・骨格のみ | 参照動画の動き（DWPose） |
| 標準：動画→動画・骨格＋深度 | 剣道おすすめ。竹刀・防具の形も深度で固定 |

動画→動画には カスタムノード **comfyui_controlnet_aux** が必要です。骨格・深度の検出モデルは初回実行時に自動でダウンロードされます。

**実測（RTX 4060 Laptop 8GB・480×272・剣道の試合動画 2.5秒＝41フレーム）**

| ワークフロー | 時間 | 結果 |
|---|---|---|
| 文章→動画（17フレーム） | 約75秒（モデル読み込み込み） | 動く。ただし防具・竹刀の形は不正確になりやすい |
| 動画→動画・骨格のみ | 約2分 | 選手の位置はおおむね追従。背景に関係ない物が出ることがある |
| 動画→動画・骨格＋深度 | 約6分（初回は深度モデル1.25GBのダウンロードで約7.5分） | **一番正確**。選手の位置・構え・竹刀の位置が元動画に合う |

832×480・5秒（81フレーム）は、この約4〜5倍の時間が目安です。正確さを上げるには、1人を近くから撮った動画を使ってください。

「🔌 ComfyUI 接続チェック」を押すと、ComfyUI に届くか・GPU で動いているか・ノードとモデルファイルがそろっているかを確認し、足りないものと置き場所を表示します。

自分で作ったワークフローを使う場合は、従来どおり「読込」で選んでください。

### ComfyUI の準備（RTX 4060 8GB の場合）

1. ComfyUI をインストールして起動（`http://127.0.0.1:8188`）
2. 8GB VRAM で動かしやすい動画モデルを使う
   - **Wan 2.2 TI2V 5B** または **Wan 2.1 T2V 1.3B**（ComfyUI の「テンプレート」→ Video にあります）
   - **LTX-Video**（高速）
3. テンプレートを開き、正のプロンプト欄に `%PROMPT%`、負のプロンプト欄に `%NEGATIVE%` と書く
   （書かなくても最初のプロンプト欄に自動で差し込みます）
4. 一度 ComfyUI 上で生成できることを確認してから、メニュー →「Export (API)」でJSONを保存
5. このサイトの「🎬 動画設定」→ ワークフロー「読込」でそのJSONを選ぶ

### 使い方

- 「段落ができたら自動でクリップを作る」にチェック → 物語が進むたびに裏で素材を作ります（物語の生成は止まりません）
- 各段落の下の「動画素材を作る」で個別に作成・作り直し
- 「🎬 動画を書き出す」→ 足りない素材を作ってから MP4 を書き出します

### 映像の一貫性のコツ

「映像スタイル・キャラクターの外見」に英語で、絵柄と人物の見た目を具体的に書いてください。
毎回のシーン指示の先頭に付くので、クリップ間で人物の見た目がそろいやすくなります。

## 🥋 動画→動画（動きを正確に再現）

剣道などの**実際の動画の動き**をそのまま使い、見た目だけをAIで作り変えます。
骨格（ポーズ）で動きを固定するので、文章だけで作るより動きがずっと正確になります。

### しくみ

1. 参照動画を動画モデル向けに整える（832×480・16fps・81フレーム＝約5秒ずつに分割）
2. 各チャンクを ComfyUI の**制御付きワークフロー**（DWPose で骨格を抽出 → Wan VACE で生成）に送る
3. 全チャンク同じシードで生成し、元と同じフレーム数に揃えて結合（タイミングがずれません）
4. 元の音声（気合・打突音）を戻し、**元動画｜AI動画** を並べた比較動画も作成

### 準備（RTX 4060 8GB）

1. ComfyUI に以下を入れる
   - カスタムノード **comfyui_controlnet_aux**（DWPose 骨格抽出）
   - モデル **Wan 2.1 VACE 1.3B**（8GB で動く。14B は VRAM 不足）
2. ComfyUI のテンプレート「Wan VACE Control Video（動画制御）」を開き、制御の前処理に **DWPose Estimator** を入れる
   （剣道は竹刀が細いので、**DWPose＋Depth（深度）を合成**すると竹刀の位置も安定します）
3. 「Load Video」ノードのファイル名を `%VIDEO%`、プロンプト欄を `%PROMPT%` / `%NEGATIVE%` にする（無くても自動で探します）
4. 「Export (API)」で保存し、「🥋 動画→動画 → 読込」で選ぶ

サイズ・フレーム数・fps・動きへの忠実さ（strength）・シードはこのサイトが自動でワークフローに設定します。

### 正確に作るコツ（剣道）

| 項目 | おすすめ |
|---|---|
| 参照動画 | 固定カメラ・全身が映る・横から撮影・明るい場所 |
| プリセット | 「🥋 剣道」で防具・竹刀・持ち方の英語指示と崩れ防止のネガティブが入ります |
| 動きへの忠実さ | 1.0〜1.2（上げるほど元の動きに忠実、上げすぎると画質低下） |
| シード | 気に入った結果のシードを固定すると同じ見た目で作り直せます |
| 確認 | 比較動画で、打突のタイミングや足さばきが元と一致しているか確認 |

物語の段落に「🥋 参照動画の動きを使う」を付けると、その段落の映像も参照動画の動きで作られます。

## ⏱ 5秒ごとのプロンプト（最大30秒）

5秒ごとに何が起きるかを最大6コマ入力すると、30秒までの1本の動画を作ります。

- 参照動画があれば **その動き＋コマごとの指示**（動画→動画）、無ければ **文章から生成**（テキスト→動画）
- 空欄のコマは直前のプロンプトを引き継ぎ、最後に入力したコマで終わります
- 全コマ共通の見た目は「見た目の指示」、ネガティブ・強さ・シードも共通（全コマ同じシード）
- 「🥋 剣道の例を入れる」で、構え → 攻め → 面 → 残心 → 小手面 → 蹲踞・礼 の6コマが入ります

### 注意（8GB GPU）

MiniMax のような大きな文章モデルと動画モデルを同じGPUで同時に動かすと、メモリ不足になります。
その場合は、先に物語を書き終えてから文章モデルをアンロードし、「未作成の素材をまとめて作成」を使ってください。
